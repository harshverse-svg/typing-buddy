# Typing Buddy Recording & Screenshot Guide

This guide describes how to capture the demo GIF and official screenshots on your Windows desktop for GitHub.

---

## Target Specifications

- **Width:** 800 px recommended (scaled down from 1080p/4K).
- **Format:** Optimized `.gif` (for `demo.gif`) and `.png` (for screenshots).
- **Target File Size:** Under 5 MB for `demo.gif` to ensure instant loading on GitHub.
- **Recommended Free Tool:** [ScreenToGif](https://www.screentogif.com/) (free, open source) or OBS Studio.

---

## 1. Demo GIF (`assets/demo.gif`)

**Scenario (approx. 8–10 seconds total):**
1. Open a clean Notepad window.
2. Type: `diff` $\rightarrow$ Wait 1 second as suggestion pill shows `different`, `difficult`. Press `F2` to complete.
3. Type: `recie ` (with space) $\rightarrow$ Notice fuzzy correction `receive` appears. Press `Tab` to accept.
4. Type: `she go` $\rightarrow$ Notice `✎ goes` grammar suggestion pill appears with `Subject-verb agreement` subtitle. Press `Tab` or `F2` to accept.
5. Save capture as `assets/demo.gif`.

## 2. Word Suggestions Screenshot (`assets/screenshot-word.png`)

1. Open Notepad.
2. Type `diff` so that the floating overlay appears right at the text cursor displaying:
   `[1] different  [2] difficult  [3] difference`
3. Take a window crop screenshot (`Win + Shift + S`) showing Notepad and the overlay.
4. Save as `assets/screenshot-word.png`.

## 3. Grammar Suggestion Screenshot (`assets/screenshot-grammar.png`)

1. Open Notepad.
2. Type `she go` so that the grammar replacement pill appears:
   `[1] ✎ goes` with subtitle `Subject-verb agreement`.
3. Take a clean window crop screenshot.
4. Save as `assets/screenshot-grammar.png`.
